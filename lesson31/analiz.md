# Анализ проблемы медленной загрузки поста в приложении Reddit

## Контекст
Приложение развёрнуто из образов `ghcr.io/codeby-devops/*:bug` с интеграцией Zipkin. Пользователи жалуются на долгую загрузку страницы с конкретным постом (например, `/post/123`). Остальные страницы работают нормально.

## Результаты трейсинга
Используя Zipkin, были проанализированы трейсы запросов к странице поста. Выявлено:

- Общее время обработки запроса: **6.1 секунды**.
- Основная задержка приходится на вызов сервиса `comment` для получения комментариев к посту: `GET /comments?post_id=123` — **3.98 секунды**.
- Внутри сервиса `comment` запрос к MongoDB `find comments for post` занимает **3.9 секунды**.

## Корневая причина
В коллекции `comments` отсутствует индекс по полю `post_id`, используемому для фильтрации. При каждом запросе MongoDB выполняет полное сканирование коллекции (`COLLSCAN`), что приводит к линейному росту времени ответа с увеличением числа комментариев.

## Рекомендуемое исправление
Создать индекс в коллекции `comments` базы данных сервиса `comment`:

```javascript
db.comments.createIndex({ post_id: 1 })
